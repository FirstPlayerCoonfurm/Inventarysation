Тестовое приложение для проведения инвентаризации.
Под "капотом" у приложения Python + Flask, само приложение запускается в изолированном контейнере со всеми нужными зависимостями

В контейнере так же запускается база данных, но можно изменить конфигурацию и подключать уже созданную базу даннх Postgresql

Приложение будет тестироваться, а так же дорабатываться для улучшения работы или расширения функционала

В плане реализация механизма регистрации с разделением должностных обязанностей, а так же гостевого режима, в котором можно будет просматривать некоторые страницы; Так же в планах реализовать функцию по смене ориентации приложениия (с IT инвентаризации, на инвентаризацию прочего оборудования вроде мебели: парт, столов, стульев, диванов и т.д и т.п), а так же корректировка функций IT инвентаризации.
